# TRPG Prep

面向 GM 的离线优先 TRPG 备团工作台。上传你有权使用的 PDF，选择需要准备的范围，TRPG Prep 会把它整理为可追溯的事实、可复核的备团产物和桌边运行视图。

> **0.1.4a0 · 预发布版本**
> 当前正式支持 **现实恐怖板块**。奇幻冒险和通用备团仍在开发，界面入口不代表完整可用性。

## 现在能做什么

- **现实恐怖**：从指定 PDF 页范围提取和复核事实，生成地点卡与章节总览，在运行模式中按地点浏览线索、时钟、展示材料和 GM 备注。
- **来源可追溯**：备团内容保留源文件和页码；模型草案需要 GM 显式复核和批准。
- **离线优先**：项目数据、上传文件和运行状态默认保存在本机；只有启用模型服务时才会向你配置的提供商发起请求。

## 安装与启动

### 运行环境

- Windows
- 首次启动需要网络，用于下载项目自己的 `uv`、Python 3.11 和运行依赖
- 不需要预先安装 Python、pip 或 uv；启动器会把它们放在用户目录和独立的运行环境中

### 选择启动方式

| 文件 | 适合的场景 | 行为 |
| --- | --- | --- |
| `start.bat` | 首次启动、准备环境、排查报错 | 自动准备运行环境并同步依赖；显示控制台日志；启动成功后手动打开 `http://127.0.0.1:8000`。 |
| `start.vbs` | 日常使用 | 在后台启动同一服务，隐藏黑色控制台，并在服务响应后打开默认浏览器。 |
| `stop.bat` | 结束使用 | 终止监听 `8000` 端口的进程。不要让其他程序占用该端口。 |

建议第一次先双击 `start.bat`。它会下载并准备 Python 运行环境、创建独立运行环境并安装依赖；确认能够正常启动后，日常可改用 `start.vbs`。首次准备可能需要几分钟，之后启动器会复用本地缓存。`start.vbs` 会隐藏错误，启动失败时请回到 `start.bat` 查看日志。

## 第一次备团

1. 启动后打开 `http://127.0.0.1:8000`。
2. 在工作台上传自己有权使用的 PDF，并创建新项目。
3. 选择要处理的页范围，例如 `159-165, 172`，并选择 **现实恐怖** 板块。
4. 让系统完成语义分段，在候选复核区检查、编辑、拆分或合并内容。
5. 将确认的内容送入书架，生成整板备团产物；检查后再批准。
6. 组装运行计划，进入桌边运行模式。

模型生成的内容是草案，不会自动成为事实或桌边资料。请始终以原始模组和你的桌上判断为准。

## 连接模型

工作台顶部的 **模型连接** 使用 OpenAI 兼容接口。当前版本在界面中保存 `Base URL`、模型 ID 和 API Key，不读取 `.env` 或环境变量。

1. 取消勾选 **使用离线 FakeLLM**。
2. 填写服务商提供的 **API Base URL**、模型 ID 和 API Key。填写 API 地址，不要填写服务商网页地址。
3. 点击 **测试连接** 读取模型列表；随后选择模型并保存。
4. 用一个小范围任务确认实际生成效果。模型列表能读取不等于一次生成已经成功。

API Key 输入框留空时会保留此前保存的密钥。密钥和工作数据保存在本机 `data/` 下；不要将该目录上传到公共仓库或发送给他人。

勾选 **使用离线 FakeLLM** 可测试界面与工作流，但它返回的是确定性示例数据，不能替代真实模型的备团结果。

### OpenRouter：低频免费试用

OpenRouter 是当前推荐的低频试用入口：

- `Base URL`：`https://openrouter.ai/api/v1`
- 在 OpenRouter 创建 API Key 后粘贴到工作台。
- 模型先填 `openrouter/free`。这是会自动选择当前可用免费模型的路由器；若它没有出现在列表中，也可以直接输入该 ID。
- 免费路由适合体验和低频使用，可能遇到限流、临时不可用或较高延迟。想固定某个免费模型时，请以 OpenRouter 的实时模型目录/API 返回的精确 ID 为准。

参考：[OpenRouter API Authentication](https://openrouter.ai/docs/api_reference/authentication) 和 [Free Models Router](https://openrouter.ai/docs/guides/routing/routers/free-router)。

## 数据与隐私

- 本机运行数据、上传 PDF 和模型配置都在 `data/`，该目录默认不纳入 Git。
- 请不要上传无权处理或不应发送给模型服务商的资料。
- 启用第三方模型时，相关提示和待处理内容会发送到你选择的服务商；请在使用前阅读其隐私和数据保留政策。

## 常见问题

**第一次启动很慢？** 首次启动需要下载 `uv`、Python 3.11 和依赖；网络完成后，后续启动会复用缓存。

**浏览器没有自动打开？** 使用 `start.bat` 后手动访问 `http://127.0.0.1:8000`。隐藏启动器会等待服务响应，准备环境期间不会立即打开空白页面。

**启动器提示无法准备环境？** 确认当前网络允许访问 GitHub 和 PyPI，再重新运行 `start.bat`。启动器会校验下载的 `uv` 文件；校验失败时不要手动运行未知来源的安装程序。

**`start.vbs` 没有反应？** 改用 `start.bat`。前者会隐藏控制台，无法直接看到 Python、依赖或端口错误。

**端口被占用？** 先确认没有其他程序使用 `8000`，再运行 `stop.bat` 后重试。

**我想参与开发或维护？** 请从 [维护与研发文档](docs/README.md) 开始；用户操作说明只在本页维护。
