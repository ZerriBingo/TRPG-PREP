# 长篇备团采用可审核的章节、拍与剧情线结构

长篇模组无法按页码切出有叙事意义的备团范围。长篇备团在事实复核后提出冒险章节、跨章节剧情线，以及只属于单一章节、用于组织该章节不同局势组合的拍，交由 GM 审核。页码仅用于来源追溯，章节不是来源分区、固定 session 数量或运行路线。剧情线不区分主线或支线。

## Considered Options

- 维持页码切片：无法可靠表达叙事阶段，已被实际工作流否决。
- 纯模型自动分章、免复核：违反本产品"候选必须 GM 复核"的核心原则，不采用。
- 建立模组地图：需要额外的空间与实体图精确度，偏离叙事备团目标，不采用。

## Consequences

- 事实可以支持多个章节和剧情线；剧情线可跨章节，拍只属于一个章节，并选择该章适用的剧情线。事实可以保留为全局参考材料。
- 每条已提升事实必须明确归入章节、全局参考、展示材料或有理由的暂缓状态，不能在结构整理中静默消失。
- 短篇模组可以退化为单章节与少量剧情线，不增加用户步骤。
- 结构整理在事实复核后分层执行：局部观察归纳拍与剧情线提及，全局阶段只读取压缩索引，不一次读取全部原始事实。
- 剧情线在章节中的角色使用引入、推进、回收和背景，不把 A/B/C 或场外进展冒充来源事实。
- 环境卡可以独立运行；人物、对手和钟的关联是可选检索提示，不是预设遭遇。
- 用户确认整套结构后，一次产物任务生成全部已确认章节。实现可按章节内部规划以控制请求大小，但必须保留跨章节剧情线，并对每章执行事实覆盖闭包校验。
