# 0.1.6a1 预发布说明（草稿）

> Alpha 预发布。现实恐怖板块保持正式支持，奇幻冒险仍为预发布板块；产物需要 GM 审核。

## 这一版做了什么

- **生成失败恢复**：空正文、截断、JSON 与校验失败都在同一步骤内有界处理；失败的尝试与诊断持久保留，成功步骤按“输入与契约身份相同”精确复用。
- **持久分窗与预算**：大范围规划按持久窗口拆分；共享请求预算随一级窗口数确定（`min(64, max(16, B+15))`），已成功的精确结果在规模拒绝之前复用。多单元请求固定 32000 completion，单单元 12000 并允许一次升至 16000；概览素材化固定 16000，其余卡片与直接生成保持 9000，同时以 `max_budget` 夹紧历史更大的预算。
- **共享规划语义**：整范围、多单元窗口、单叶与离线探针使用同一套紧凑规划契约，携带完整事实投影和来自真实响应模型的输出边界说明；地点、闭包、条件、时钟分支与来源认识状态的职责按板块选择。
- **身份判断**：身份重整读取完整事实闭包，成功判定的每个簇（含单例）都有稳定身份，未判定块按“无判定”处理；模型报告一张卡承载多位可分人物时停止产物任务，而不是照常落地。
- **来源忠实性**：缺口字段用显式空引用表达，来源限定语原样保留。
- **brief 事实闭包与章节归属**：`field_sources` 的显式引用并入自身 `fact_ids`；未知、越范围、跨章节引用点名失败；合并时不再静默截断，超过 100 项显式报错。

## 兼容与缓存

- 无新增业务数据迁移；已批准的既有资料不会被自动重写。
- 规划提示契约升到 v24、素材化 v16：旧版本的成功或失败记录不作为新契约的结果；同版本内输入与契约身份相同的成功步骤仍精确复用；旧缓存不被清除。

## 已知限制

- 整章端到端成功率、全部卡片语义与“一小时准备两小时游戏”未验收。
- 奇幻冒险仍未完成真实质量验证。
- 部分可访问地点的入口、条件与空间描述的来源忠实性仍待处理。
- brief 合并超过 100 个事实时显式失败；简单拆窗不能解除最终并集上限。
- 16000 概览预算只有有限样本支持，不构成稳定上界；上游费用与耗时随请求规模变化。
