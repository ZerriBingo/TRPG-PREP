# 下一轮：双板块备团验收样例与证据口径

R1–R6 本轮切片与 R7 后端共享生成接口已签收。下一步回到产品目标：让 GM 能运作世界、设计遭遇、查到手头资源，避免预设玩家路线。前端进一步拆分只有在实际维护或使用证据显示收益时再定，不因文件长而自动开始。

## 本次具体交回

制作一份精简的双板块验收包，复用已有领域字段和运行能力，不增加产品字段、面板、自动化引擎或兼容入口：

1. 两份明确标注“合成材料”的小样例，使用自行撰写的中性文字，不引用真实模组正文。现实恐怖样例应包含可描述/回访的地点、至少一个有目标且可扮演的人物、社会障碍、线索与可变化的压力；奇幻样例应包含局势与势力目标、可选支线、一次有叙事目标及非歼灭出口的冲突、可用环境资源。两份都允许玩家绕路、改变接触顺序，不以作者顺序规定行动。
2. 为每份样例写出少量实际的 GM 查阅问题、已有卡型应承载的信息及来源对应关系，例如“此人要什么，什么条件会改变立场”“玩家临时去另一个地点时我拿什么描述”“战斗的目标、变化和其他出口是什么”。用现有契约表达期望，缺口要指明是内容未提供、投影丢失、无法检索还是运行状态不当改变，不靠新增必填字段填平。
3. 给出可重复的演练步骤与评分表：一次性整理单列；后续从确定本次需要的资源到准备选择、查阅、自由切换、保存/续团，分别记录完成时间、返回原文次数、答不上来的问题、出处可信度和是否被迫预设路线。将“首次整理”“每次备团”“现场查阅”分开记录，不混为一个耗时。
4. 核对并引用现有自动检查能覆盖哪一步。若要验证样例与当前契约一致，可复用临时库和现有 Fake client；不要新建平行测试框架。Fake/手工期望只能验证流程及验收工具，不能证明真实模型质量。交回应明确下一次新生成与真人演练需要收集的证据，不能提前宣布时间目标通过。

## 范围与停止条件

本次为验收准备，不改生产行为，不顺手实现发现的产品缺口。样例与评分口径足够让另一位维护者独立演练后即可交回；如果已有合成夹具可以复用，应补齐问题/期望映射，避免重复造一套内容体系。

只读取代码、公开契约和已有合成夹具，不读取正式业务正文、调用真实模型或修改正式库。真实资料/模型的后续演练应按届时授权范围执行；没有实际新产物和使用记录就保留质量与备团时间结论为空。原模组、生成正文、密钥及数据库不进入公开文档。

更新 backlog/audit 的当前入口，交回样例、评分表、复用说明和证据限制。保持两工作区其他未提交改动，不提交、推送或发布。
