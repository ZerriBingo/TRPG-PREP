# 三板块产物契约

本文件定义新项目应生成什么。三个板块各自独立验收、互不替代；从来源到桌边素材的分层关系见 [产品护栏](./PRODUCT_GUARDRAILS.md) 的“三层边界”。

## 共同约束

- 每张产物必须引用已提升事实，并为每个有内容的字段保存来源事实 ID。
- 模型缺少依据时写入待确认问题，不补写原文没有的数值、动机、因果或玩家路线。
- 展示材料是保留原页的记录；工具不裁剪、不保存用户截图，也不让模型重写玩家可见正文。
- 产物由 GM 编辑、批准后进入运行计划。运行状态不回写产物正文。

## 现实恐怖

### 必要产物

- `location`：每个具名、可访问、可折返、可调查、可求助或可推动叙事的地点独立成卡。字段包含常态、抵达描述、相关人物、直接/隐藏线索、GM 响应、首次触发、后果、展示材料引用、离开条件和回访变化。
- `chapter_overview`：跨地点情势、真相、主要线索链、重要人物、结局与章节级后果。

### 按需产物

- `npc`：人物在调查中的功能、需求、可提供内容、施压点和拒绝后果。
- `threat`：表现、意图、危险前兆、升级和非战斗出口。
- `clock`：暴露、追击、仪式或局势变化的阶段与推进条件。
- 展示材料记录：地图、信件、照片、报纸、日志或档案的来源页与 GM 备注，可绑定地点。

### 不生成

- 独立通用场景卡。
- 线性正确路线。
- 仅因地点较小而把它藏入主地点摘要。
- 默认敌人数值面板。

## 奇幻冒险

奇幻冒险以可运行局势为中心。环境不等于战斗地图；探索、社交、穿越、战斗和事件都可以由环境卡牵头。一个局势可以在这些形态之间变化，不应因此生成彼此重复的场景卡。

### 必要产物

- 冒险章节总览：冒险前提、当前压力、适用剧情线、重要人物或阵营、章内的拍、结果和待确认问题；它属于经审核的冒险章节，不是普通卡片，也不规定运行顺序。剧情线可以跨章且不分主次，拍只属于一章，组织该章游戏中可运作的剧情线组合。
- `environment`：主要运行表面。字段应覆盖环境倾向、开场画面、叙事功能、冲动、可利用要素、危险、位置关系、GM 响应、触发、阶段变化和退出结果。
- 拍负责一次可能游戏的叙事焦点：逐条说明所选剧情线本次可能的变化、后续悬念及相互影响。这些是可调整的备团建议，不是来源事实或固定剧本。环境从来源中的独立可运行局势规划，再关联适用拍；不按拍标题复制出卡，也不强制一拍对应几张环境。

### 按需产物

- `npc`：非敌对或立场可变人物的短期目标、长期目标、可交换内容、关系压力和态度改变条件。
- `enemy`：明确对抗者的动机、当前目标、标志行动、危险前兆、受创变化、撤退或投降条件，以及战斗之外的解决方式。
- `encounter_clock`：援军、警报、崩塌、追击、谈判耐心、仪式或阶段变化。
- 有叙事意义的旅途：由 `environment` 以穿越倾向表达；普通移动直接略过，不生成独立旅途卡，也不形成必经顺序。

环境卡是运行锚点；NPC、敌人和遭遇钟可以通过可选关系提示相关性，但不预先组成必须出现的遭遇。奇幻板块不生成世界地图、战斗地图或遭遇平衡结果。

### 数值与角色边界

- 原文数值只作为有来源的参考。工具可以把旧型模拟数值解释为叙事职能与可用运行素材，作为可复核建议连同原始数值和来源一并给出。
- 不做机械换算，也不把该建议当作另一规则的难度、伤害、生命、压力或遭遇预算；不得声称完成了数值平衡或产出了与官方等价的数据。
- 首版只生成连接当前角色的提问或待确认项。未来的队伍信息由 GM 独立输入，不并入来源事实。

### 不生成

- 只以“击败全部敌人”为目标、缺少叙事功能的战斗摘要。
- 与环境卡重复的通用场景卡。
- 自动换算或凭空补写的目标规则数值。
- 按原文页序推导的强制路线。

## 通用备团

通用备团服务于不适合前两个板块的规则和题材，例如科幻恐怖、忍者、武侠或其他小众系统。它不是现实恐怖或奇幻冒险的中间阶段。

它应提供尽可能跨题材稳定的结构：

- 情势与目标。
- 可访问地点或运行单元。
- 人物/阵营功能。
- 威胁意图、前兆、升级与退出。
- 时间压力和后果。
- 来源索引与未决问题。

通用备团不自动输出具体规则数值，不假设固定战斗结构，也不借用另外两个板块的规则名称作为内部或用户可见 ID。
